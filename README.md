# 🪔 Diwali Universe 2026

**An interactive festival of light by Akhil Alladi.**

A premium, multi-page Diwali experience built with semantic HTML, CSS and browser-native JavaScript. Includes Canvas fireworks, interactive diyas, optional user-initiated sound and a shareable greeting generator.

## Run locally

This is a static website. Open `index.html` in a browser or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

GitHub Actions publishes the repository root to GitHub Pages when changes are pushed to `main`. In **Settings → Pages**, select **GitHub Actions** as the source.

## Accessibility and privacy

- Reduced-motion preferences are respected by the fireworks engine and CSS transitions.
- Sound is disabled by default and requires an explicit user action.
- No analytics, account system, backend or API keys are used.
- Fireworks are visual browser animations only, not pyrotechnics.
