# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the `main` branch. Older commits and preview branches may not receive security updates.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older releases and commits | No |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues, Discussions, pull requests, or social posts.**

Use GitHub's **Private vulnerability reporting** feature on this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide the details requested by GitHub and submit the report privately.

Please include, where possible:

- A clear description of the vulnerability and its potential impact.
- The affected file, component, route, dependency, or commit.
- Reproduction steps or a minimal proof of concept.
- Any prerequisites or configuration needed to reproduce it.
- A suggested mitigation, if you have one.

The maintainer will review the report, may request additional details, and will coordinate a fix and disclosure with the reporter. Please allow reasonable time for investigation and remediation before sharing details publicly.

### Private reporting availability

Private vulnerability reporting must be enabled in the repository's **Settings → Security & analysis** for the reporting flow above to be available. If GitHub does not show **Report a vulnerability**, do not post the details publicly; contact the repository maintainer privately through their GitHub profile instead.

Thank you for helping keep Diwali Universe and its users safe.
